# Маршрутизация через Hysteria 2 на Keenetic

Скрипт работает вместе с [H-wave](https://github.com/for6to9si/H-wave). Для устройств, которым назначена политика `Hwave`, российские IP-адреса идут напрямую, остальные - через Hysteria 2. Списки российских адресов скрипт берёт у [IPdeny](https://www.ipdeny.com/) и обновляет раз в сутки.

Это разделение по IP-адресам, а не по списку заблокированных сайтов. Сайт на зарубежном CDN может пойти через VPN, даже если он российский. H-wave перехватывает только порты, указанные в его настройках; скрипт не расширяет этот список.

## Что нужно

- Keenetic с Entware и работающим H-wave.
- Доступ к командной строке Entware (`~ #`). Команды ниже не предназначены для KeeneticOS CLI (`(config)>`).
- Свободное место на `/opt` и доступ роутера к `ipdeny.com`.

На Keenetic Giga KN-1012 с H-wave 2.12.2 проверены загрузка списка IPv4 и правила `iptables` в таблицах `nat` и `mangle`. IPv6 и работу после перезагрузки роутера проверьте отдельно на своём устройстве.

## Установка

Сначала убедитесь, что Hysteria работает:

```sh
/opt/etc/init.d/S96hysteria status
```

В командной строке Entware установите зависимости и скачайте скрипт:

```sh
opkg update
opkg install curl ipset
curl -fL https://raw.githubusercontent.com/artemk1337/hysteria2-keenetic/main/S99georoute -o /opt/etc/init.d/S99georoute
chmod 700 /opt/etc/init.d/S99georoute
/opt/etc/init.d/S99georoute start
```

Подождите минуту и проверьте результат:

```sh
/opt/etc/init.d/S99georoute status
ipset list ru_geo4 | head
iptables -t nat -S hwave | head
iptables -t mangle -S hwave | head
```

Статус должен быть `running`. В обеих цепочках `hwave` должна стоять строка `--match-set ru_geo4 dst -j RETURN` перед `REDIRECT` или `TPROXY`. Если строки нет, откройте журнал и пока не назначайте политику устройствам:

```sh
tail -40 /opt/var/log/georoute.log
```

Если в H-wave включён IPv6, проверьте его тем же способом:

```sh
ipset list ru_geo6 | head
ip6tables -t nat -S hwave | head
ip6tables -t mangle -S hwave | head
```

Для IPv6 ожидается строка `--match-set ru_geo6 dst -j RETURN` в обеих цепочках. Отсутствие цепочки `hwave` означает, что H-wave сейчас не перехватывает IPv6 в этой таблице.

## Подключение устройств

В веб-интерфейсе Keenetic назначьте политику доступа `Hwave` сначала одному устройству. Проверьте на нём российский и зарубежный сайты, затем назначьте политику остальным. Новые устройства тоже нужно назначать политике, если в интерфейсе роутера не настроено правило для них.

После проверки откройте пару сайтов и посмотрите счётчики правил:

```sh
iptables -t nat -L hwave -n -v --line-numbers | head
```

При обращении к российскому IP должен расти счётчик правила с `ru_geo4`. Для зарубежного IP трафик должен доходить до `REDIRECT`. Счётчики показывают попадание в правила, а работу туннеля проверяйте открытием сайта с устройства.

## Откат и обновление

Чтобы отключить разделение, выполните:

```sh
/opt/etc/init.d/S99georoute stop
```

После этого H-wave продолжит направлять трафик назначенных ему устройств через Hysteria. Чтобы убрать автозапуск скрипта, удалите файл после остановки:

```sh
rm /opt/etc/init.d/S99georoute
```

Скрипт каждые 30 секунд восстанавливает свои правила после перезапуска H-wave и раз в сутки обновляет списки IP. При сбое загрузки остаётся прежний список. Его состояние и ошибки записываются в `/opt/var/log/georoute.log`.
